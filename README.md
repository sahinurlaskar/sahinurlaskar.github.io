# Dr. Sahinur Rahman Laskar — Academic Website

A responsive, static academic portfolio prepared using the supplied CV and the requested reference websites as design inspiration. Built with HTML, CSS, and vanilla JavaScript; no build process or backend is required.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, theme variables, light/dark styling
- `script.js` — mobile navigation, dark mode, publication filtering, current year
- `assets/profile.jpg` — your profile photo
- `assets/resume.pdf` — latest supplied CV

## Preview locally
Open `index.html` in a modern browser. For best results, you can use VS Code's Live Server extension, but it is not required.

## Publish on your existing GitHub Pages website
1. Download and extract the ZIP.
2. Back up or clone your existing repository first: `https://github.com/sahinurlaskar/sahinurlaskar.github.io`
3. Copy the contents of this folder into the root of that repository, preserving the `assets/` folder.
4. Review the page and update any information that has changed.
5. Commit and push to the branch configured for GitHub Pages. The website should update after the Pages deployment completes.

## Before publishing
- The profile photo is `assets/profile.jpg` (taken from your CV). Replace that file with a higher-resolution image of the same name if you have one.
- Publication section contains a curated selection, not all papers. The supplied CV is linked for the full list.
- Verify all counts, position dates, awards, profile URLs, and publication metadata before publishing.
- The email address and professional-profile links were taken from the supplied CV.
- This is an independently prepared design inspired by the general structure of academic portfolio websites; it is not a copy of another person's source code.
